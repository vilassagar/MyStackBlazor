# MyStackBlazor.Core

Core abstractions for the [MyStackBlazor](https://www.nuget.org/packages/MyStackBlazor) component library: lightweight state containers (`MsStore`, `MsStoreConsumer`) shared by the UI packages.

You normally get this package transitively through `MyStackBlazor`. Reference it directly only when you build your own components on top of the store primitives.

```bash
dotnet add package MyStackBlazor.Core
```
